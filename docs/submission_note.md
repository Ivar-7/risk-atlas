# Nairobi flood CAT prototype — submission note

## Data and model

The portfolio is the starter kit's 600 **synthetic** Nairobi buildings (KES 6,363,470,000 total insured value), not a cedant or Kenya Re portfolio. The five supplied GeoTIFFs are a constructed pluvial susceptibility proxy based on terrain and mapped river/stream signals, not measured flood depth. The starter kit provides 24 approximate coordinates for 37 named flood-prone areas; the common proxy flags 12 of those 24 centres.

For each building and source tier, a positive 0–1 susceptibility score activates a fixed damage ratio from the five-tier construction matrix; zero gives zero modelled damage. The score is not converted to depth. The matrix is informed by the [JRC Africa residential depth-damage table](https://publications.jrc.ec.europa.eu/repository/bitstream/JRC105688/global_flood_depth-damage_functions__10042017.pdf#page=16), but its class-by-tier percentages are assumptions, not JRC values or Kenya claims calibration. [The full matrix and its limits](assumptions.md) are documented. Ground-up loss is damage ratio × building TIV. Gross insured loss applies each building's assumed deductible and policy limit, then sums payouts across the portfolio. The workspace sets those terms as percentages of each building's TIV; the starter portfolio contains no verified policy terms. The default 0% deductible and 100% limit leave gross loss equal to ground-up loss. The portfolio treaty waterfall then cedes a selected quota-share percentage of aggregate gross loss and applies an optional catastrophe excess-of-loss layer to retained event loss. The result is a separate net EP curve and net AAL; default 0% cession and no cat layer leave net equal to gross.

The five source tiers have no measured event frequencies. Scenario names follow common=10, occasional=25, moderate=50, severe=100 and extreme=250 years. The supplied masks have the opposite footprint order, so the model uses source extreme, severe, moderate, occasional and common respectively. The resulting exceedance curve and integrated annual average loss depend on this assumption and are unsuitable for underwriting without calibration. Scenario detail also displays a 10,000-year conditional gross-loss simulation derived from those five points. Its bootstrap band reflects sampling variation under the same assumptions; the 1-in-500 and rarer losses extrapolate the final slope, rather than using additional hazard data. The optional drainage uplift is a deterministic, **unvalidated sensitivity** around proxy-missed hotspot centres. Its effect is shown against the same model without uplift; the centres used to construct it cannot independently validate its accuracy.

## AI contribution

When the selected Gemini or OpenAI provider has a configured API key, the exposure preview uses a model to extract explicitly stated building count, class, place and value per building from a synthetic residential offer. The underwriter reviews those rows before submission. The saved run records the offer text, extracted groups, returned model and response ID, review time, and a comparison against the same portfolio without the added rows. The rows change TIV and the loss curve; a deterministic rules preview is explicitly labelled as non-AI. A reviewed building-coordinate CSV can also supply exact sampling points for those extracted rows; the bundled example contains no building coordinates, so it uses synthetic positions. [The demo](ai_exposure_demo.md) describes the workflow. [Current v1.3.0 replay evidence](current_ai_replay_evidence.json) records a saved, reviewed `gpt-6-luna` extraction that adds 25 synthetic Kibera buildings, KES 20,000,000 TIV, and KES 5,400,000 to the assumed 1-in-100 gross loss. The replay reused the prior AI extraction and made no new AI call. [The original live-demo file](live_ai_demo_evidence.json) documents a separate extraction under the previous vulnerability method; its loss figures are historical.

## Limits

The hazard layer misses drainage-driven flooding, as the 12/24 centre check illustrates. Approximate neighbourhood centres can also miss nearby flooded streets. Event frequencies, fixed class-by-tier damage ratios, policy and treaty terms, and any new exposure locations are assumptions. No building-level schedule for the added demo exposure, real client portfolio, measured pluvial depths, local claims calibration or independent validation of the drainage uplift is included. The coordinate upload validates raster coverage and agreement with reviewed AI groups but cannot independently prove a building's address. The simulated tail and bootstrap band do not measure real catastrophe uncertainty. The treaty model has one aggregate event layer and no reinstatements or annual aggregate limit. Model outputs should be presented as prototype estimates.
